# Oladunni Rachael — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or serve the folder with a local development server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy
Upload the folder to Netlify or Vercel as a static site, or deploy the repository with GitHub Pages.

## Before publishing
- Add live repository/demo links to each project card when available.
- Confirm the email and social profile URLs in `index.html`.
- Add a downloadable CV link if you want one.
- Review project descriptions and status labels for accuracy.
